# Snapload ⚡

موقع لرفع الملفات بسرعة. بعد الرفع يحصل المستخدم على كود من 5 خانات (حروف وأرقام)، وبكتابة الكود يتم تحميل الملف من أي جهاز.
تُحذف الملفات تلقائياً بعد ساعة من آخر تحميل (أو من الرفع إذا لم تُحمّل أبداً).

## التشغيل محلياً

```bash
npm install
npm start          # http://localhost:3000
npm test           # اختبار شامل: رفع، تحميل، حد الحجم، الحذف التلقائي
```

## الإعدادات (متغيرات البيئة)

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `PORT` | `3000` | منفذ الخادم |
| `UPLOAD_DIR` | `./uploads` (في Docker: `/app/uploads`) | مكان حفظ الملفات |
| `MAX_FILE_MB` | `500` | أقصى حجم للملف بالميجابايت |
| `TTL_MINUTES` | `60` | مدة بقاء الملف بدون تحميل |
| `MAX_STORAGE_MB` | `5120` | أقصى مساحة لكل الملفات معاً (يرفض الرفع بعدها) |
| `MIN_FREE_MB` | `512` | مساحة تبقى فارغة دائماً على القرص |
| `TRUST_PROXY` | `1` | عدد البروكسيات أمام التطبيق (CranL = 1). لا تضعها `true` |
| `UPLOADS_PER_10MIN` | `20` | عدد مرات الرفع لكل IP كل 10 دقائق |
| `LOOKUPS_PER_MIN` | `60` | عدد طلبات البحث/التحميل لكل IP في الدقيقة |
| `FAILED_LOOKUPS_PER_15MIN` | `20` | عدد الأكواد الخاطئة لكل IP قبل حظره 15 دقيقة |

## النشر على CranL

1. في لوحة CranL: **GitHub** ← اربط حسابك ووافق على تطبيق CranL.
2. **Projects** ← أنشئ مشروعاً، ثم **Applications** ← **New Application** واختر هذا المستودع (فرع `main`).
3. Build type: **Dockerfile**، والمنفذ (Port): **3000**.
4. أضف Volume باسم `uploads` ومسار التركيب (mount path) **`/app/uploads`** حتى لا تضيع الملفات عند إعادة النشر، ثم أعد النشر.

## كيف يعمل

- `POST /api/upload` رفع ملف (حقل `file`) ← يرجع `{ code }`.
- `GET /api/file/:code` معلومات الملف (الاسم والحجم).
- `GET /d/:code` تحميل الملف، وكل تحميل يمدد صلاحيته ساعة.
- الأكواد لا تحتوي على الأحرف المتشابهة (0/O/1/I/L) وغير حساسة لحالة الأحرف.
- تنظيف تلقائي كل دقيقة، وحد لعدد المحاولات لكل IP لمنع تخمين الأكواد.

## الحماية

- **منع تخمين الأكواد:** بعد 20 كوداً خاطئاً من نفس الـ IP يُحظر 15 دقيقة (حتى عن الأكواد الصحيحة)، ولا يمكن تجاوز ذلك بتزوير `X-Forwarded-For`.
- **الملفات المرفوعة لا تُعرض أبداً في المتصفح:** تُرسل دائماً كمرفق `application/octet-stream` مع `CSP: sandbox`، فرفع ملف HTML أو SVG لا يمكنه تشغيل سكربت على الموقع.
- **أسماء الملفات:** تُحذف منها رموز التحكم وعلامات الاتجاه المخفية (التي تُستخدم لتمويه الامتداد مثل `photo‮gpj.exe`).
- **حماية المساحة:** حد للحجم الكلي ومساحة فارغة دنيا، ورفض الطلبات الكبيرة قبل قراءتها.
- **رؤوس أمان:** CSP صارمة، HSTS على HTTPS، `X-Frame-Options`، `nosniff`، `Referrer-Policy`، `Permissions-Policy`.
- **منع الرفع من مواقع أخرى** عبر `Sec-Fetch-Site`.
- رسائل الخطأ لا تكشف تفاصيل داخلية، و`npm test` يختبر كل ما سبق.
